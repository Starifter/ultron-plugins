Stripe's hosted MCP server: read and manage customers, products, prices, invoices,
payment links and refunds, and search Stripe's documentation.

After installing, run `/mcp login stripe`. Sign in to a **test-mode** account first if you
are trying it out: its tools can create real charges and refunds in live mode, and every
call goes through your permission mode.
