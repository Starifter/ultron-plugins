Figma's hosted MCP server: read the design context of a frame - its layout, styles,
variables and components - to generate code that matches, and write native content back
to Figma Design, FigJam and Slides.

After installing, run `/mcp login figma` (or press *Sign in* on its page) and approve Ultron in the browser. Figma decides which apps may connect; if the sign-in is refused, Figma
has not opened its server to Ultron.
