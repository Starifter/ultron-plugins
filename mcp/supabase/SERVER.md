Supabase's hosted MCP server: list projects, read table schemas, run SQL, apply
migrations, read logs and advisors, and manage edge functions and branches.

After installing, run `/mcp login supabase` (or press *Sign in* on its page) and approve Ultron in the browser. It can change a database: try it on a development project first, and
keep production behind your permission mode.
