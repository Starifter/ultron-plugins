Railway's hosted MCP server: see your projects and services, deploy, read deployment and
build logs, and manage environment variables.

After installing, run `/mcp login railway` (or press *Sign in* on its page) and approve Ultron in the browser. Deploys and variable changes go through your permission mode like any
other tool call.
