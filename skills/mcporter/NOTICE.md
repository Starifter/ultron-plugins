# Notice

The `mcporter` skill is adapted from OpenClaw's skill of the same name (`openclaw/openclaw`,
`skills/mcporter`, commit `73f67dc`). It keeps OpenClaw's command reference, updated
against mcporter 0.15, and adds rules that keep it beside Ultron's own MCP connection rather
than a way round it: a call through it is only an `exec` line in the trail, and adding a
server stays the person's. It shipped bundled with Ultron until it moved here.
